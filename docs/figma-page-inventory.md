# Vellora Health route inventory

## Architecture

- **Web.** 51 App Router page files, including three role aliases. Next.js 15.5.29, React 19.3.1, TypeScript 5.9.3, Tailwind CSS 3.4.19, Lucide 0.475.0, Recharts 3.10.1, React Hook Form 7.92.0 and Zod 4.6.7 from the installed packages. CSS custom properties, next/font, typed SVG wrappers, and three shared role layouts sit under src.
- **Companion app.** 12 screens under vellora-health-mobile/src/app. Expo 58.0.25, Expo Router 58.0.31, React 19.3.0, React Native 0.88.1, and React Native Web 0.21.4. Expo route groups and bottom tabs provide navigation. Theme, icons, components, and fixture data live alongside the screen code.
- **Runtime data.** src/lib/db.ts supplies typed fixtures and in-memory mutations. The web auth context stores a mock session identifier in sessionStorage. A Prisma schema exists, and the reviewed route code uses the client store. Expo starts with a demo patient and uses its own context and fixture data.
- **Assets.** public/assets contains logos, avatars, illustrations, photography, and icons. public/vellora_facilities_assets_complete contains additional packaged facility assets. The Expo app has its own assets/images folder. The root static HTML/CSS/JS files and _original_source preserve legacy work. Existing audit and mobile design-reference images were treated as history.

## Review method

All 48 rendered web templates were opened at 1440 × 960, with a representative fixture for each parameterized template. The responsive web review covers 390 × 844 samples, and the Expo review covers 12 routes using its browser renderer at the same viewport. The Expo home and services catalog were rechecked after mobile source changes appeared during handoff. Untested mobile widths are marked as source-supported where the layout has responsive rules. Native device runtime was outside the verification scope.

Each table row records implemented behavior. A rendered route establishes visual evidence. The interaction report records the smaller set of click-through journeys exercised end to end. Photo and logo names are sampled from the rendered DOM. CSS backgrounds and component SVG vectors are noted separately.
