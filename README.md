# Vellora Health — Complete Landing Page

A responsive, multi-section HTML/CSS/JavaScript landing page based on your Vellora Health design references.

## Open locally

Double-click `index.html` in a modern browser. No build process or npm is needed.

## Contents

- `index.html` — page structure and semantic content
- `styles.css` — design system, desktop/tablet/mobile layout, gradients, components
- `script.js` — navigation, carousels, FAQ, booking form demonstration
- `assets/` — locally included images, including imagery cropped from design mockups and user-provided reference screenshots

## Sections

Home hero · Services · Specialties · Doctors · Patient experience · Testimonials · Facilities · FAQ · CTA banner · Footer

## Important before launch

This is a **design/demo prototype**, not a live medical website. `135k+` trust messaging, ratings, provider profiles, doctor names, patient testimonials, availability/insurance statements, and imagery are sample design content, **not verified business facts**. Replace with approved clinic content and properly licensed imagery. The appointment form only previews requests and does not transmit or store any personal information; connect a compliant scheduling backend and implement privacy/security controls before production use.

Google Fonts are loaded when online; browser system fonts are used offline. All images are local.

### Navbar update
The navigation bar is transparent and shares the full-bleed photographic hero background (including behind the header). No separate navbar color band is used.
